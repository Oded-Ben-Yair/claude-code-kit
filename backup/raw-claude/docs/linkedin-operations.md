# LinkedIn Operations Rules (On-Demand Module)

Load when: LinkedIn, post, comment, engage, connection, DM, apply, job search

## Algorithm Rules (2025-2026)

### Distribution Pipeline
- **Quality check** (0-60 min): Initial credibility screening
- **Golden window** (60min-2hr): Critical — 3-5 substantive comments here trigger wider distribution
- **Relevance matching** (2-8hr): Algorithmic expansion based on early signals
- **Extended distribution** (8-24hr+): Viral phase for high-performers

### Signal Hierarchy (by weight)
1. **Saves** (~5x a like) — end posts with "Save this for later"
2. **Substantive comments** (15+ words, 5-7x a reaction)
3. **Comment threads** (multi-person back-and-forth, 5.2x amplification)
4. **Shares/sends** (via DM)
5. **Dwell time** (61+ sec = 15.6% engagement rate)
6. **"See more" clicks**
7. **Reactions** (all types equal weight — LOWEST signal)

### Penalties
- External links in post body: **-40-60% distribution** → put links in FIRST COMMENT
- 5+ hashtags: penalty triggered
- Engagement bait ("Comment YES"): active suppression
- Engagement pods: shadowban without notification
- Posting >1x/day: reduces reach ~30%
- Generic "Great post!" comments: effectively ZERO weight

## Post Format Specs

| Format | Engagement Rate | Optimal Length | Notes |
|--------|----------------|---------------|-------|
| Carousel (PDF) | 5.9-6.6% | 9 slides, 1080x1350px | Hook on slide 1, CTA on last |
| Document | 5.85% | 6-10 pages | Deep dives, research summaries |
| Native video | 5.6% | 30-90 seconds | Vertical, captions mandatory |
| Text + image | ~4.2% | 1,300-1,600 chars | Most stable format |
| Poll | 4.4% | 2-4 options | Opinion-sparking, not yes/no |
| Text-only | ~4% | 1,300-1,600 chars | Under 500 = low-effort penalty |
| External link | PENALIZED | — | Never in post body |

## Posting Rules

### Timing
- **Primary**: Tuesday/Thursday 10:00-10:30 AM IST
- **Secondary**: Thursday 5:00 PM IST (catches US overlap)
- **Never**: Friday, weekends, after 7:30 PM
- **Frequency**: 2-3 posts/week max. Never >1x/day.

### Content Rules
- Stay niche: multi-LLM routing, Voice AI, Azure production, RAG evaluation
- Technical case studies > thought leadership (IC, not executive)
- Framework posts get job offers; hot takes get likes (12K viral = 0 leads vs 2.3K framework = 3 leads)
- 3-5 hashtags at END of post, PascalCase: #MachineLearning #ArtificialIntelligence + 1-2 niche
- Start in medias res (concrete event), never with generic thesis
- Include one real metric or constraint per post

### Human-Likeness Checklist (Before Publishing)
- [ ] Sentence lengths vary (1 short + 1-2 medium + 1 longer per section)
- [ ] No formulaic structure (varies from last post)
- [ ] Contains one "fingerprint detail" (time, tool, log line, constraint)
- [ ] Has a scoped opinion (not generic "it depends")
- [ ] Contains 1-2 controlled imperfections (fragment, blunt aside)
- [ ] No engagement bait CTA ("What do you think?" is fine; "Comment YES" is not)
- [ ] Doesn't end with engagement question every time (sometimes just stop)

### MANDATORY: Pre-Comment Quality Gate (Anti-AI Detection)
**Every comment MUST pass the 12-gate system in `content/templates/comment-templates.md` BEFORE posting.**
Failure to run the gate = AI-detectable patterns on Oded's live profile = credibility damage.

Quick reference (full gates in templates file):
1. **Kill the Validation Sandwich** — no "[Nice opener] + [Evidence] + [Axiomatic closer]" pattern
2. **Fingerprint Check** — no repeated phrases across comments in same session
3. **Genuine Messiness** — 1 in 4 comments needs casual abbreviation, hedge, or filler
4. **Blurt Test** — 2 of every 5 comments must be blurts (no narrative arc, <5 sec mental effort)
5. **Cadence Breaker** — 1 of every 4 comments must break standard sentence rhythm (run-on, fragments, mid-thought start)
6. **Effort Variation** — mix throwaway one-liners with multi-paragraph depth
7. **Punctuation Personality** — allow parentheticals, trailing thoughts, imperfect grammar
8. **Tone Variation** — mix formal/casual/blunt across comments, include genuine uncertainty
9. **Word-Level Scan** — zero Tier 1 banned words, zero emoji, zero exclamation marks, **NEVER describe emojis in words** (e.g., "צחוק עם דמעות" instead of 😂 = instant AI tell)
10. **Polished Phrasing** — 15-entry banned consulting-speak list (auto-fail)
11. **Dash-Free** — ZERO dashes of any kind in comments/DMs
12. **Batch Audit (ENFORCED)** — side-by-side comparison of ALL session comments before posting: shape, length, structure, tone collision
- **Self-Reference Cap** — max 50% of comments per session can reference Oded's production systems

### MANDATORY: Final Notification Sweep Before Session Close

After completing all planned interactions, re-check notifications ONE MORE TIME before declaring session complete. New notifications arrive during the session (replies to comments you just posted, likes on your activity). Missing these wastes the golden window for reciprocal engagement.

Origin: LinkedIn Day 17 (2026-02-23) — user caught missed notification re-check after Barak Mor reply.

### Hebrew Content: User-Authored Workflow

AI-generated Hebrew reads as translated. For Hebrew comments/replies:
1. AI writes draft to `content/reply-{name}-draft.txt` with context (original post, their reply, our comment)
2. User edits the Hebrew text
3. AI posts the approved version via Playwright

NEVER post AI-generated Hebrew without user review. English comments can be AI-drafted and posted directly after user approval of the text shown in chat.

**Bidi Safety for Hebrew Drafts**: When Hebrew text contains English brand names (OpenClaw, OpenAI, Anthropic), replace with Hebrew transliterations (אופנקלואו, אופן אי איי, אנתרופיק) matching the original post's style. Mixed LTR/RTL renders garbled in terminal and txt editors. Keep English instructions ABOVE a separator line (`===`), Hebrew text BELOW.

Origin: LinkedIn Day 17 (2026-02-23) — user rejected AI Hebrew draft on Amir Ben Ari post ("not good hebrew").
Origin: LinkedIn Day 17 afternoon (2026-02-23) — bidi mixing of English brand names in Hebrew txt file rendered garbled. Fixed with Hebrew transliterations.

**User edits always improve Hebrew drafts.** AI drafts serve as a starting point for structure and context, but user consistently adds: (1) natural Israeli conversational cadence, (2) personal conviction/angles the AI misses, (3) cultural nuance (e.g., "חיי אדם אל מול אלמנטים טכנולוגיים" added depth to a generic concession). Present drafts as starting points, not final text.

Origin: LinkedIn Day 19 (2026-02-24) — user improved 3/3 Hebrew drafts. AI draft for Sahar reply was generic "good point"; user added autonomous car / human lives angle that elevated the reply.

**Hebrew Draft Anti-Pattern: Generic Observations.** AI drafts that describe systems abstractly ("validation loop checks itself, falls to fallback") read as AI-generated. Drafts that include ONE specific concrete example ("fixed a bug that didn't exist and broke a feature that worked") + a punchy closer ("it's not that it's wrong, it's that you don't know when") pass immediately. Rule: always lead with a specific incident, end with a blunt observation. Never describe system architecture in Hebrew comments.

Origin: LinkedIn Day 21 (2026-02-25) — first Amir Ben Ari draft rejected ("too generic, feels AI"). Rewritten with specific example + punchy closer, approved instantly.

**Hebrew/English Code-Switch is Natural.** Israeli professionals naturally mix Hebrew with English idioms on LinkedIn. "if it works it's not stupid" embedded in a Hebrew comment is an anti-AI signal because AI tends to write pure Hebrew. Use code-switching when it fits the thought naturally, especially with common English idioms or tech terms.

Origin: LinkedIn Day 21 (2026-02-25) — user's Omri Barak comment style mixed Hebrew with English idiom. More authentic than pure Hebrew draft.

### Thread Depth Protocol (Comment Replies)

| Thread Depth | Action |
|-------------|--------|
| 1 (your comment) | Full engagement, production angle |
| 2 (their reply, your reply) | Add substance, can self-reference |
| 3 (back-and-forth) | Shorter, concede if they push back |
| 4+ (deep thread) | Graceful close. Do NOT extend unless they ask a direct question |

On viral posts (50+ reactions), thread depth 3-4 is HIGH visibility. Every reply appears in feeds of both participants' networks. Close gracefully, don't argue with the post author on their own viral post.

Origin: LinkedIn Day 19 (2026-02-24) — 4-reply thread on Sahar Carmel's viral post (26→76+ reactions). Graceful concession at depth 4 was the right call.

### Comment on Fresh Viral Posts (< 1 Hour Old)

Early comments on posts that are gaining traction get maximum visibility. LinkedIn's "most relevant" sort pushes early substantive comments to the top. If a notification shows a fresh post from a connection with 10+ reactions already, comment immediately.

Origin: LinkedIn Day 19 (2026-02-24) — commented on Sahar's post at 26 reactions (1hr old). Post reached 76+ reactions. Our comment thread had 4 exchanges with the author, 63+ impressions on our comment.

## AI Formatting Hard Bans (Quick Reference)

**Full list**: `research/ai-formatting-bans.md`

**BANNED WORDS** (Tier 1 -- flagged by GPTZero/Originality.ai): delve, leverage, spearhead, harness, navigate, robust, seamless, tapestry, landscape, transformative, revolutionary, game-changer, dive into, multifaceted, pivotal, utilize, foster, realm, underscore, paradigm, synergy, holistic, intricate, embark, testament, thrilled, meticulous, elevate, empower, unpack
**BANNED PHRASES**: "In today's rapidly evolving...", "It's worth noting", "Here's the thing", "Let me be clear", "At the end of the day", "Moreover/Furthermore", "In conclusion", "I'm thrilled/excited to share", "I'm humbled to", "Unpopular opinion:", "Read that again", "Let that sink in"
**PUNCTUATION**: **ZERO dashes in comments/DMs** (-, --, em dash, en dash — absolute ban, friend flagged as AI tell). Max 1 em dash/post (posts only). Zero semicolons in posts/comments. Max 1 ellipsis/post. Max 1 exclamation/post, zero in comments.
**STRUCTURE**: Never Hook+3-blank-lines+Body+CTA. No lists of exactly 5 or 7. Vary paragraph lengths (mix 1-sentence with 4+ sentence). No summary/conclusion paragraph. 2 in 5 posts must end WITHOUT a question.
**OPENINGS**: Never start 3 consecutive posts with "I". Never open with question+blank lines, "In today's...", "Have you ever...", "Picture this:", "Let me share..."
**EMOJI**: 0-2 per post, 0 per comment. Never as bullet markers. Never fire/rocket/brain/gem as formatting.
**CTA**: "What do you think?" max 1 in 5 posts. BANNED: "Thoughts?", "Comment YES", "Tag someone", "Share if you agree", "Drop a [emoji]"
**TONE**: Include 1 genuine uncertainty per post. Mix formal + blunt. No corporate motivational. No teacher-to-student.
**SENTENCES**: Vary lengths (std dev 8+ words). Never 3+ consecutive same-word starts. Include fragments.
**PRE-POST AUDIT**: Word scan (Tier 1 list) -> phrase scan -> structure differs from last post -> has personal detail only you'd know -> has one uncertainty moment
**PRE-COMMENT AUDIT**: Run 8-gate quality system from `content/templates/comment-templates.md` — MANDATORY for every comment before posting on Oded's profile

## Recruiter Monitoring Process

### Daily Inbox Check (5 min, 17:00 IST)
1. Open LinkedIn Messages tab
2. Filter for InMail (recruiter messages have "InMail" badge)
3. Check for responses to sent DMs and connection requests
4. Any recruiter contact → log immediately in `tracking/recruiter-inmail-log.md`

### Response Protocol
| InMail Type | Response Window | Action |
|-------------|----------------|--------|
| Recruiter InMail (relevant role) | Within 24 hours | Respond with interest + schedule call. Use response templates from recruiter-inmail-log.md |
| Recruiter InMail (wrong role) | Within 48 hours | Polite redirect — specify your niche (production AI, multi-LLM, voice AI) |
| Hiring manager DM | Within 12 hours | Highest priority. Personalized response referencing their work/company |
| Connection request from recruiter | Within 24 hours | Accept + send warm DM within 24h of accepting |
| Follow-up from prior contact | Within 24 hours | Continue conversation, suggest next step |

### Weekly Log Review (Thursday 15:20, part of weekly review)
1. Open `tracking/recruiter-inmail-log.md`
2. Check for any NEW status items without responses
3. Update status on all active conversations
4. Note patterns: which companies, which roles, which sources
5. Update monthly summary at month-end

### Escalation Triggers
- 0 recruiter InMails after 6 weeks of active posting → review profile keywords, check SSI score, increase posting frequency
- 3+ InMails/week → profile is working, focus shifts to conversion (call scheduling, interview prep)
- InMail for a SHIP company (Gong, Monday) → drop everything, respond within 4 hours

### What NOT to Do
- Never ignore an InMail, even if not interested — always respond (builds reputation score)
- Never respond with a form letter without personalizing the first line
- Never discuss salary in the first message — wait for screening call
- Never share CV in first reply without knowing the role details
