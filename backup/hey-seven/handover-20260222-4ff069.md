## Critical Learnings for Next Session

1. **Always review teammate code before committing** — 3 CRITICALs shipped because lead committed without reading. The `get_responsible_gaming_helplines()` bug existed for 6 review rounds.

2. **Gemini 2.5 Flash is unreliable for structured output** — thinking budget consumes output tokens, truncating JSON ~50%. Use `gemini-2.0-flash` + `method="json_schema"` for any `with_structured_output()` task.

3. **After adding per-tenant params to a function, grep ALL callers** — missing params silently fall back to defaults. `grep -rn "function_name" --include="*.py" | grep -v "param_name"` catches them.

4. **E2E mock LLMs must handle ALL Pydantic schemas** — missing `InjectionClassification` caused fail-closed blocking. Trace every `with_structured_output()` call before writing E2E tests.

5. **Avoid words "pipeline", "deploy", "push" in task subjects** — TaskCompleted hook triggers deployment verification even for local-only work.

6. **Pre-existing test failures (52 in test_api.py)** are all 401 auth issues from API_KEY env var. Not regressions. Fix requires either unsetting API_KEY or adding auth headers to test client.
