**4 @tool functions** in `src/agent/casino_tools.py`:
- `check_comp_eligibility(guest_tier, occasion)` → wraps CompStrategy engine, returns real comp data

- `lookup_upcoming_events(venue_type, interest)` → parses entertainment-guide.md, returns venue info

**Per-agent tool mapping** in `src/agent/agents/tool_binding.py`:
- comp + host: 4 tools (full toolkit)
- dining + entertainment + hotel: 2 tools (events + tiers only)

**Tool-call loop** in `src/agent/agents/_base.py` (lines 1332-1434):
- Binds tools BEFORE semaphore acquisition (line 1332)
- After `llm.ainvoke()`, checks for `tool_calls` in response (line 1387)
- Executes each tool synchronously (pure business logic, no I/O)
- Appends ToolMessages, re-invokes LLM (max 1 round)
- Error-safe per tool — individual tool failures don't crash the loop
- Feature-flagged: `tool_use_enabled` defaults to False
