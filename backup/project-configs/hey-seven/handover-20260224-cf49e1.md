## THE CRITICAL LEARNING (Read This First)

**Internal review scored 96.7/100. External 4-model consensus scored 65/100. 31-point gap.**

This is the most important finding of the entire Hey Seven project. The gap has 5 root causes:

1. **Same-model self-review** — Opus reviewing Opus code for 45 rounds finds issues in the same categories but never discovers new categories of problems. Fresh models find what we normalized.

2. **Incremental scoring** — Each round credits deltas for fixes. But we never re-scored the entire codebase from zero. A fresh reviewer sees `asyncio.to_thread()` and scores 5/10; we scored +0.5 for "fixing the blocking issue."

3. **Calibration rule hid problems** — "If code didn't change, restore previous score" prevented any fresh assessment of existing patterns. R47 retired this rule.

4. **Fix validation gap** — R46 moved Redis I/O inside async lock (per R45 reviewer suggestion). R47 GPT-5.2 flagged this as CRITICAL: lock+I/O = head-of-line blocking. We fixed one bug by creating another because we didn't validate the fix approach.

5. **Neutered tests** — All tests disable auth middleware and semantic classifier. Production's two most impactful code paths have zero integration coverage. 4/4 models flagged this.
