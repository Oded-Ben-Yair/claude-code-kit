### Agentic Perfection Categories

#### 1. Semantic Understanding
- **Sarcasm detection**: Guest says "Oh great, another 30-minute wait" → agent recognizes frustration, not satisfaction
- **Intent disambiguation**: "Can I get a table?" → dining reservation vs gaming table vs hotel front desk
- **Multi-turn context**: Track conversation thread across 10+ turns without losing context
- **Implicit requests**: "It's getting late and I'm hungry" → proactively suggest open late-night dining

#### 2. Guest Profiling for Human Hosts
- **Real-time data extraction**: Pull guest preferences, party size, occasion, dietary restrictions from natural conversation
- **Profile handoff**: When guest escalates to human host, provide a structured brief: "Sarah, party of 4, celebrating anniversary, shellfish allergy, prefers quiet dining, has been frustrated about wait times"
- **Cross-session memory**: Remember returning guests — "Welcome back! Last time you enjoyed the steakhouse. Would you like me to make a reservation?"
- **Sentiment trajectory**: Track guest mood across the conversation — flag to human host if sentiment is declining

#### 3. Data Pulling Skills
- **Live availability checking**: Real-time restaurant wait times, show ticket availability, hotel room inventory
- **CMS integration**: Pull latest menu changes, event schedules, promotional offers from Google Sheets CMS
- **External APIs**: Weather for outdoor dining suggestions, local events, transportation status
- **Comp eligibility**: Query player tier data to offer appropriate comp levels

#### 4. Human-Likeness & Conversational Quality
- **Persona consistency**: Seven maintains personality across long conversations (currently drifts after 10+ turns)
- **Natural pacing**: Vary response length — not every answer needs 3 paragraphs
- **Proactive suggestions**: Based on context, time of day, guest profile — "Since you mentioned you're here for the weekend, the Saturday comedy show has great reviews"
- **Graceful handoffs**: When escalating to human host, the transition should feel warm, not robotic
- **Cultural sensitivity**: Adapt tone for different guest demographics

#### 5. Agent-Human Host Collaboration
- **Pre-visit intelligence**: Before a VIP arrives, Seven compiles a brief for the human host with preferences, history, special occasions
- **Real-time assist**: During floor interactions, human host can query Seven for quick lookups ("What's the Ascend tier benefit for spa?")
- **Post-interaction logging**: Human host logs interaction details, Seven incorporates into guest profile
- **Escalation intelligence**: When Seven escalates, it provides context so the human host doesn't ask the guest to repeat themselves

### Implementation Approach
- Start with sarcasm/sentiment detection (VADER is too basic — need LLM-based nuanced classification)
- Build guest profile handoff API (structured JSON → human host dashboard)
- Integrate live data sources (CMS webhook already exists, extend to availability APIs)
- A/B test persona variations for human-likeness
- Each capability should have its own ADR + test suite + review round
