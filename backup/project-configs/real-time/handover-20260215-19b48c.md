## Session Discoveries & Learnings

### Key Learnings
1. **VAD 2.0s produces fewer but longer segments** — 34 vs 44 segments. Not worth the latency increase since both produce 100% clean Hebrew.
2. **Timeout increase is safe** — increasing from 5s to 10s doesn't slow fast responses (avg still 1.7s). Only affects the tail for long segments.
3. **Context window 5 works well** — no measurable latency impact, potentially better coherence.
4. **Env var config enables rapid A/B testing** — change via `az webapp config appsettings set`, app restarts, test with new params.

### Patterns to Keep
- A/B testing via env vars + `az webapp config` (no redeploy needed)
- One variable at a time methodology
- Same 532s test file for consistent comparison
- Log analysis via `translation_io` events for Hebrew quality audit

### Patterns to Avoid
- VAD above 2.0s (no quality gain, worse latency and segment risk)
- Translation timeout below 10s (long segments fail)
