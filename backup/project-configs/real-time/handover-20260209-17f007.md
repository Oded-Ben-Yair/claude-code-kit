## Architecture Doc v2.2 — Key Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Deployment | Azure App Service (NOT Functions) | Functions has 10-min timeout, incompatible with 20+ min WS calls |
| Audio capture | pyaudiowpatch + soxr | Only maintained lib with WASAPI loopback; soxr for HQ resampling |
| Transcription | ElevenLabs Scribe v2 raw WebSocket | Full control; SDK abstracts too much |
| Diarization | v1 WITHOUT it | Scribe v2 Realtime has NO diarization; diart adds 1-3s latency |
| Translation | Gemini 2.5 Flash (primary), GPT-5.2 (fallback) via openai SDK | Best latency-quality tradeoff |
| Frontend auth | HTTP-only session cookie | Browser WebSocket API cannot send custom headers |
| Agent auth | JWT Bearer in Authorization header | Python websockets lib supports custom headers |
| JWT refresh | In-band over active WebSocket | Calls exceed 15-30 min TTL; 60s grace period |
