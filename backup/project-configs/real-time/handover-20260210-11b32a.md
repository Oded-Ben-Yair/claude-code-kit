## Key Decisions

1. **SameSite=none for production cookies** - Required because SWA and App Service are on different domains. Cross-origin cookies need `SameSite=none; Secure`. Local dev keeps `SameSite=strict` with `Secure=false`.
2. **VITE_API_URL env var** - Frontend uses `apiUrl()` helper that prefixes backend URL in production, empty string in dev (Vite proxy handles routing).
3. **ARCHITECTURE CHANGE for next session** - Replace local-agent WASAPI capture with browser MediaStream API.

## Key Learnings

1. `az webapp up` deploys from CWD root - wrong for monorepo. Must create custom zip with correct package structure.
2. Oryx needs `requirements.txt` at deployment root (not nested in subdirectory).
3. Cross-origin cookies need `SameSite=none; Secure` - `SameSite=strict` silently blocks cross-domain cookie sending.
4. Pydantic Settings `.env` loading populates the Settings model, NOT `os.environ`. Module-level `os.getenv()` won't see `.env` values.
