## Key Learnings (IMPORTANT)

### HeyGen Video Agent Behavior

1. **Duration is calculated from script length** - if you provide 650 characters, it will extend to 38+ seconds regardless of what you request

2. **Scene count must be EXPLICIT** - saying "key visuals" results in 5 generic scenes; you must specify "8 SCENES" with numbered breakdown

3. **Separate SPOKEN from ON-SCREEN TEXT** - HeyGen tries to speak everything unless you explicitly mark what's spoken vs displayed

4. **Timestamps give control** - providing "SCENE 1 (0-3s)" prevents agent from deciding pacing

### The Math
- ~650 characters Arabic = 120 words = requires 50+ seconds at natural pace
- For 26 seconds, need ~300 characters spoken only
- Additional content goes as ON-SCREEN TEXT
