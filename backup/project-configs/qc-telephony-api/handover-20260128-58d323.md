## Key Achievements

### 1. Dynamic Language Support
- Removed fixed `SourceLanguage`/`TargetLanguage` enums
- Accepts any ISO language code (ar, es, pt, en, he, fr, de, zh, ja, etc.)
- GPT-5 handles translation for any language pair
- Language-specific prompts for common languages (AR, ES, PT, HE)
- Generic prompt fallback for unknown languages

### 2. Session Memory (Azure Table Storage)
- New `SessionMemoryService` using Azure Table Storage
- Storage account: `stqctelephonyapi`
- Table: `callsessions`
- TTL: 20 minutes (configurable via `SESSION_TTL_MINUTES`)
- Auto-extends on follow-up queries

### 3. Telephony Format Endpoint
- New endpoint: `POST /api/telephony/translate`
- Response mirrors input structure exactly
- Adds `translation` field inline per segment
- Adds `translatedAt` timestamp

### 4. Simplified Q&A Response
- Removed `confidence` field per sys admin request
- `relevantSegments` now uses `SegmentReference` (index, speakerId, start, end)
- Supports first query (with segments) and follow-up (without segments)
