### Architecture Decisions

1. **Route Group Pattern**: Root layout is pure HTML shell (`app/layout.tsx`). Arabic chrome in `app/(ar)/layout.tsx`. Non-Arabic locales in `app/[locale]/layout.tsx` with `NextIntlClientProvider` + `LocaleHtmlAttrs` component.
2. **SSR-Safe Scroll Reveal**: `useScrollReveal` defaults visible, hides below-fold on client, 500ms safety timeout ensures content always shows.
3. **Static Export**: `output: 'export'` with `setRequestLocale()` in every [locale] page for next-intl compatibility.
4. **No next-intl middleware**: Direct `import()` for messages instead of `getMessages()` (avoids `headers()` in static export).
