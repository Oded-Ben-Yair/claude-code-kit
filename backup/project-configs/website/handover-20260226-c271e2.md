## Key Architecture Notes

### i18n Architecture (Critical for Issue 1)
- Locale detection: `hooks/useLocale.ts` reads from URL path prefix
- Messages: `messages/{ar,en,es,pt}.json` — flat key-value structure
- **Data files are Arabic-only**: `lib/data/brokers.ts`, `articles.ts`, `forecasts.ts`, `services.ts`
- To fully i18n the data, either:
  - (A) Create per-locale data files (`brokers.ar.ts`, `brokers.en.ts`) — high effort
