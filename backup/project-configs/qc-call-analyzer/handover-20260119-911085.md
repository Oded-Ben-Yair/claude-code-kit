## Root Causes Found

### Bug 1: Azure STT 25-Minute Limit
- Azure `gpt-4o-transcribe-diarize` has a **hard 1500 second (25 min) limit**
- Code had 55-minute threshold - files under 55 min were NOT chunked
- Result: 49-min file was silently truncated to ~7 minutes

### Bug 2: Translation Pipeline Missing Chunking
- `translate_enhanced()` in `enhanced_translator.py` had NO chunking
- Full 29k char transcript sent to GPT in single call
- Result: Only partial translation returned (456 chars for Hebrew)

### Bug 3: Durable Functions Replay
- `force_reprocess=true` used same instance_id
- Durable Functions replayed cached activity results
- Result: Old truncated data kept appearing

### Bug 4: Mutagen Duration Detection
- `mutagen` library returned ~7 min instead of ~49 min for some files
- Chunking decision was based on wrong duration
- Fix: Use `known_duration_seconds` from database
