## Quick Reference for Next Session

### How to Modify Agents
```bash
# Source API key
export ELEVENLABS_API_KEY=$(python3 -c "import json; print(json.load(open('backend/local.settings.json'))['Values']['ELEVENLABS_API_KEY'])")

# PATCH agent settings or prompt
curl -X PATCH "https://api.elevenlabs.io/v1/convai/agents/${AGENT_ID}" \
  -H "xi-api-key: $ELEVENLABS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"conversation_config": {"agent": {"prompt": {"prompt": "NEW PROMPT HERE"}}}}'

# Verify after PATCH
curl -s "https://api.elevenlabs.io/v1/convai/agents/${AGENT_ID}" \
  -H "xi-api-key: $ELEVENLABS_API_KEY" | python3 -m json.tool
```
