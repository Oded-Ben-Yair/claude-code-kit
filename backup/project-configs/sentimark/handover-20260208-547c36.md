**Run this query after predictions have been running for a few hours:**
```sql
-- Check gate decision distribution (should NOT be all PASS_THROUGH)
SELECT gate_decision, COUNT(*),
  ROUND(100.0*COUNT(*)/SUM(COUNT(*)) OVER(), 1) as pct
FROM gate_monitoring_log
WHERE created_at > NOW() - INTERVAL '24 hours'
GROUP BY gate_decision;
```

**If ALL decisions are PASS_THROUGH with reason 'model_not_loaded':**
The Azure Blob connection isn't configured. Fix:
```bash
# Option A: Set env var in Azure App Settings
az functionapp config appsettings set \
  -g AZAI_group -n polymarket-analyzer \
  --settings AZURE_BLOB_CONNECTION_STRING="$(az keyvault secret show --vault-name kv-seekapa-apps --name SentimarkV2-BlobConnectionString --query value -o tsv)"

# Option B: Verify Key Vault secret exists
az keyvault secret show --vault-name kv-seekapa-apps --name SentimarkV2-BlobConnectionString --query value -o tsv
```

**After predictions are evaluated (24h+):**
```sql
-- Check would-have-traded accuracy
SELECT
    gml.gate_decision,
    COUNT(*) as total,
    SUM(CASE WHEN ph.direction_correct THEN 1 ELSE 0 END) as correct,
    ROUND(100.0 * SUM(CASE WHEN ph.direction_correct THEN 1 ELSE 0 END) / COUNT(*), 1) as accuracy
FROM gate_monitoring_log gml
JOIN prediction_history ph ON gml.prediction_id = ph.id
WHERE ph.status = 'evaluated'
GROUP BY gml.gate_decision;
```
