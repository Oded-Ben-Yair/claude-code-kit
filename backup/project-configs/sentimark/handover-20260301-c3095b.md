## Key Learning
**psycopg2 InFailedSqlTransaction**: When multiple queries run sequentially on a shared psycopg2 connection, if ANY query fails, the connection enters `InFailedSqlTransaction` state. ALL subsequent queries fail silently until `conn.rollback()` is called. This caused the geopolitical query to return empty results whenever the preceding correlation query (which queries `price_history`) failed. Fix: add `try: conn.rollback() except: pass` in every exception handler.
