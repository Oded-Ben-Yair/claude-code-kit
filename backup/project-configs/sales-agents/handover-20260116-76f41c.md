## Key Decisions Made

1. **max_tokens: 300 → 500**
   - Arabic tokenization differs from English
   - 300 tokens caused truncation ("مع..." instead of "مع السلامة.")
   - 500 tokens prevents truncation with minimal latency impact

2. **Balanced prompts (~2.5k chars)**
   - Original: 8-13k chars (too verbose)
   - Ultra-compressed: 1k chars (missing critical rules)
   - Balanced: 2.3-2.5k chars (all rules, no verbosity)

3. **Gemini recommended over Claude**
   - 30% faster average latency
   - Both pass all tests
   - Claude as backup for edge cases
