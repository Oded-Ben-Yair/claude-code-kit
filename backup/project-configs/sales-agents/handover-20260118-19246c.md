### Neutral-Lock Protocol

```
Phase 1 (NEUTRAL): Use plural/neutral forms when gender unknown
  - تفضلوا، كيف الحال؟، مين معي؟

Phase 2 (DETECTION): Detect gender from:
  - Name: محمد → MALE, سارة → FEMALE
  - Adjective with ة: مهتم → MALE, مهتمة → FEMALE
  - Verb form: أبي → MALE, أبين → FEMALE

Phase 3 (LOCKED): Permanently use correct forms, never switch
  - MALE: تفضل، حالَك، تبي، عندَك
  - FEMALE: تفضلي، حالِك، تبين، عندِك
```
