## Key Learnings (Stored in Memory)

### 1. Phone Answering Design (Nouf)
- Secret client RECEIVES calls, doesn't initiate
- First message: "ألو؟" only (cautious, unknown number)
- No double "ألو" - if unclear, ask "من معي من فضلك؟"
- If caller says salam: "وعليكم السلام، من معي؟"

### 2. Kunya Strategy (Maryam)
- Ask Kunya ONCE ONLY after time confirmation
- Use gender-neutral: "من باب الاحترام بس، شو ينادونك أهلك؟"
- If skipped, use first name - never ask again
- Target: 3-4 name uses total (not 6-8)

### 3. AI Feel Reduction
- `ignore_default_personality=true` removes generic AI overlay
- SHORT opening messages - don't dump 4 elements at once
- Latency <200ms feels human, >300ms feels AI
- TDD approach: Define pass/fail FIRST, test variants, keep winner

### 4. Arabic Phone Etiquette
- CALLER initiates Salam, receiver returns it
- Receiver should be guarded answering unknown numbers
- Never introduce yourself before knowing caller identity
