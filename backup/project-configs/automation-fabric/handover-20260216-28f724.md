## Architecture Decisions

1. **is_teaser_mode pattern**: Defaults to `True` in email template via `{% if is_teaser_mode is not defined %}{% set is_teaser_mode = true %}{% endif %}`. Full template preserved with `{% if not is_teaser_mode %}` guards. Can revert to full email by passing `is_teaser_mode=False`.

2. **DISPLAY_SYMBOLS mapping**: Single `{"CLUSD": "USOIL"}` dict in orchestrator, passed to both templates and used in send script. Applied at 3 levels: (a) template ticker strips, (b) template CTAs/names, (c) data generation (trading ideas thesis, Grok market summary).

3. **Real OHLC fallback**: `{% if asset.ohlc_data %}` renders real candles, `{% else %}` keeps `generateCandleData()` as fallback.

## Learnings

- Grok-generated text inherits raw API symbols. Fix: replace CLUSD->USOIL in `generate_market_summary()` BEFORE passing to LLM.
- display_symbols must be applied at BOTH data level (trading ideas) AND template level (ticker, CTAs).
- Chart div IDs and JS `symbol` variables are internal plumbing that must stay as raw API symbol for chart rendering to work.
