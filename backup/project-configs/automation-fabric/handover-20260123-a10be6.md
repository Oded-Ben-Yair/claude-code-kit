## What Was Done

### 1. Fixed Critical Layout Issue
- **Problem**: Screenshots showed 75% white space - only first asset visible
- **Root Cause**: IntersectionObserver kept sections at `opacity: 0` when not in viewport
- **Solution**: Added static mode detection in `AssetSection.tsx`:
  ```typescript
  const isStaticMode = window.location.search.includes('static=true');
  const [isVisible, setIsVisible] = useState(isStaticMode); // Start visible in static mode
  ```
