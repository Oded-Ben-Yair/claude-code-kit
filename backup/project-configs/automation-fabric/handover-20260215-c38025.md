## Key Learnings

1. **Azure Functions deployment**: Local `pip install -t .python_packages` can produce incompatible native extensions (cffi/cryptography). Always use `--build remote` for production.
2. **SCM_DO_BUILD_DURING_DEPLOYMENT**: Must be `true` for Oryx to run `pip install`. Reset to `false` after deploy to avoid CI/CD side effects.
3. **Health endpoint timing**: Returns 200 while Kudu still processes zip — NOT a reliable "deploy complete" signal. Check deployment logs timestamps.
4. **Durable Functions message size**: Strip large payloads (OHLC data) before passing to activities to avoid 64KB Azure Storage queue limit.
