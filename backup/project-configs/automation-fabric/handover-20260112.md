## Critical Gotchas

### 1. Temperature for Gemini
**NEVER change Gemini temperature from 1.0** - causes looping and degraded output.

### 2. Division by Zero in Heat Bars
Fixed in previous session. If you see `inf%` or `NaN`, check:
```python
range_size = day_high - day_low
if range_size > 0:  # Guard against division by zero
    position = (current - day_low) / range_size * 100
```

### 3. Symbol Mapping
Internal symbols (XAU, CL, NSDQ) differ from API symbols (XAUUSD, USOIL, ^NDX).
Mapping is in `market_config.py` - `FMP_SYMBOL_MAPPING`.

### 4. Function Key Required
The Premium Plan now requires auth. Always include:
```
?code=[FUNCTION_KEY - get from: az functionapp keys list -g AZAI_group -n func-marketing-newsletter]
```

### 5. Blob Storage URLs
- Storage account: `stmarketingnewsletter`
- Container: `landing-pages`
- Pattern: `/market-overview/latest/{lang}.html` and `/market-overview/{date}/{lang}.html`
