You MUST use the enforce-capabilities skill to analyze and enrich the current plan.

## Instructions

1. **Load the Capability Registry**
   Read `~/.claude/capabilities-registry.json` to get all available agents, skills, and MCPs.

2. **Find the Current Plan**
   Look for the plan in:
   - The most recent file in `docs/plans/` matching `*-design.md` or `*-plan.md`
   - Or the plan file mentioned in the current conversation
   - Or the TodoWrite items if no file exists

3. **Analyze Each Step**
   For each plan step, determine:
   - Intent (research, parse, code, test, review, deploy, design, document, decide)
   - Complexity (simple vs multi-tool)
   - Required artifacts

4. **Match Capabilities Using Multi-Tier Approach**

   **Tier 1 - Keyword Match:**
   - Check if step text contains any capability trigger keywords
   - Match against `triggers` array in registry

   **Tier 2 - Intent Classification:**
   - Classify step intent using `step_intent_patterns` from registry
   - Map intent to appropriate capability type

   **Tier 3 - Complexity Analysis:**
   - Complex steps get multiple capabilities
   - High-risk steps get `multi-model-debate` skill
   - Decision steps get `memory` MCP

5. **Apply Matching Rules**
   - Max 1 agent per step
   - Max 2 skills per step
   - Max 2 MCPs per step
   - Confidence threshold: 0.6
   - Always consider memory MCP for architectural decisions

6. **Rewrite the Plan with Enrichments**

   For each step, add capability annotations:
   ```markdown
   3. [Original step text]
      → Agent: `agent-name` (brief reason)
      → Skills: `skill-1`, `skill-2`
      → MCP: `mcp-name`
      → Confidence: 0.XX
   ```

7. **Add Execution Metadata Block**

   Append to the plan:
   ```yaml
   ---
   # Capability Mapping (auto-generated by enforce-capabilities)
   enrichment_version: 1.0
   enriched_at: [timestamp]
   capabilities_used:
     agents: [list]
     skills: [list]
     mcps: [list]
   ---
   ```

8. **Save the Enriched Plan**
   - If plan was in a file, update the file in-place
   - If plan was in TodoWrite, update the todo items with capability notes

9. **Present for Approval**
   Show the enriched plan and ask:
   "Plan has been enriched with capability mappings. Ready to proceed with execution?"

## Key Capability Mappings Reference

### Research → Perplexity
- General research: `perplexity` MCP + `perplexity-deep-research` agent
- Academic: `perplexity-academic-researcher` agent
- Financial/SEC: `perplexity-sec-analyst` agent
- Social/trending: `grok-social-pulse` agent

### Documents → Gemini
- Parse PDFs/docs: `gemini-doc-parser` agent
- Analyze images: `gemini` MCP with HIGH resolution
- Video analysis: `gemini-video-analyzer` agent

### Code → Codex/Azure
- Implementation: `codex-max-builder` agent
- Code review: `azure_code_review` tool
- Large codebase: `gpt52-context-weaver` agent

### Decisions → Debate
- Complex decisions: `multi-model-debate` skill
- Trade-off analysis: `gpt5-pro-decision-panel` agent
- Always persist to: `memory` MCP

### UI/Design → Premium
- Design to code: `design-to-code` skill + `gemini-design-coder` agent
- Premium UI: `premium-frontend` skill
- Visual effects: `premium-effects` skill
